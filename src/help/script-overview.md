# 剧本总览

剧本总览提供对整个剧本的鸟瞰视图，帮助你快速掌握剧情规模、分支走向与素材使用情况。

---

## 仪表盘概览

顶部仪表盘实时汇总以下关键指标：

| 指标 | 说明 |
|------|------|
| 剧本总字数 | 所有对话行文本的总字数 |
| 剧情块数 | 场景标签（Label）的数量 |
| 选择支行数 | 所有选择支的行数 |
| 分支结局数 | 去重统计所有 Choice 的目标标签数 |
| 角色数 | 剧本中使用的角色数量 |
| 总行数 | 剧本总行数 |

## 双形态视图

### 卡片网格视图
每张卡片代表一个场景（Label），展示：
- 场景名称
- 首行台词摘要
- 该场景对白总行数
- 角色立绘头像列表
- 选择支数量

### 大纲视图
按行顺序展示场景头与各行内容摘要，便于快速浏览剧情节奏。

## 高级过滤

使用顶部过滤栏精确定位内容：

- **文本搜索**：匹配行类型与会话内容
- **角色下拉**：只显示包含特定角色的场景
- **维度筛选**：按「含选择支」「有背景」「有标签」等维度过滤

## 导航跳转

- 点击任意卡片或大纲行可跳转到时间轴对应位置
- 选中行会在时间轴中高亮并平滑滚动到视野中央
- 配合左侧场景导航面板实现双向联动定位
