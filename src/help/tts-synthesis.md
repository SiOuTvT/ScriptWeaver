# TTS 语音合成

TTS 语音合成为每句对话一键生成语音配音，让你的视觉小说角色真正「开口说话」。

---

## 功能概述

ScriptWeaver 内置 TTS 语音合成引擎，支持：
- 将任意对话行的文本转换为语音
- 生成的音频文件存储在项目 `assets/audio/` 目录中
- 自动绑定到对应的对话行
- 在舞台预览中可直接播放试听

## 使用步骤

### 对话行配音

1. 在时间轴中选中一条对话行
2. 在属性面板中找到「TTS 配音」区域
3. 点击「合成语音」按钮
4. 等待生成完成（通常在数秒内）
5. 生成后点击播放按钮试听

### 批量合成

在 AI 功能面板中可使用批量合成功能，一次性为多条对话行生成配音。

## 生成的音频

- 格式：MP3
- 存储位置：项目目录 `assets/audio/` 下
- 文件命名：`tts_{timestamp}_{hash}.mp3`
- 自动类型识别：生成后自动归类为「语音」类别

## 音频用途

生成的 TTS 语音可以：
- 在舞台预览中直接播放，模拟实际游戏效果
- 导出到 Ren'Py 工程中作为 `voice` 语句
- 在素材管理中查看和管理

## Ren'Py 导出

导出 Ren'Py 工程时，TTS 语音会自动映射为 Ren'Py 的 `voice` 语句：

```
voice "audio/tts_xxx.mp3"
heroine "你好，初次见面。"
```

---

## 注意事项

- TTS 合成需要有效的 API 配置，与 AI Copilot 共用密钥
- 合成过程中请勿关闭编辑窗口
- 生成的音频文件随项目 `assets/` 目录携带，项目移动/复制不影响音频播放
- 语音仅储存原始对话文本的合成版本，不会根据游戏状态动态变化
