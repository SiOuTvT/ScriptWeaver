# 导出设置

导出设置面板配置你的项目如何导出为可运行的游戏文件。

---

## 支持的目标平台

ScriptWeaver 目前支持两种导出目标：

### Ren'Py 工程

导出完整的 Ren'Py 项目文件夹，可在 Ren'Py 引擎中直接运行和发布。

导出内容包括：
- `script.rpy`：完整剧本文件（含标签、对话、选择支、过渡效果）
- `images/`：所有图像素材
- `audio/`：所有音频素材
- `gui/`：默认 UI 资源

### Web 播放器

导出可在浏览器中预览的 Web 版本：
- 单文件 HTML 页面 + 内嵌播放器
- 包含完整的剧本数据和素材引用
- 可在任何现代浏览器中打开预览

## 导出设置选项

### 基础设置
- **项目名称**：导出文件夹的命名
- **作者信息**：可选的项目作者署名
- **导出路径**：选择导出文件的目标文件夹

### Ren'Py 设置
- **屏幕分辨率**：默认 1280×720（16:9）
- **默认过渡效果**：场景切换的默认过渡
- **包含 GUI 资源**：是否一同导出基础 UI 模板

### Web 播放器设置
- **素材内嵌方式**：选择素材以 Base64 内嵌还是相对路径引用
- **背景音乐预加载**：是否在启动时预加载音频

## 导出流程

1. 完成剧本编辑后点击顶部工具栏「导出 RPY」按钮
2. 在弹出的导出设置面板中配置参数
3. 点击「导出」按钮
4. 选择目标文件夹
5. 等待导出完成
6. 在目标文件夹中找到生成的工程文件

## Ren'Py 导出规范

导出严格对齐 Ren'Py 官方 Scripting Manual：

- 不生成非法的 `zoom()` 属性调用
- 缩放效果使用标准逐行 ATL 变换或自定义 `sw_zoom` / `sw_pos` 兜底 transform
- 所有非内置过渡经过白名单校验，自动生成 transform 定义
- 缺失素材的行会降级为注释，不发射无效语句

```
# 合法输出示例
show heroine happy at sw_pos(0.3, 0.5) with moveinright
heroine "你好。"

# 缺素材时的降级输出
# show heroine happy (素材未找到)
heroine "你好。"
```

## 便携性

- 导出的 Ren'Py 项目文件夹完全独立，不依赖 ScriptWeaver
- 可在 Ren'Py 官网下载 Ren'Py SDK 后直接运行
- 整个项目文件夹可打包发布或分享给他人
