# 舞台预览

舞台预览是 ScriptWeaver 的可视化核心，实时渲染剧本中角色的立绘位置、背景画面与对话文本，让你的剧本所见即所得。

---

## 界面概览

舞台预览占据编辑器中央区域，呈现一个长方形虚拟舞台画面。预览内容包括：

- **背景**：当前行指定的背景图片，填满整个舞台
- **角色立绘**：当前行登场角色的立绘图像，支持自由拖拽定位
- **对话文本**：透明底角色对话框文本

## 基本操作

### 拖拽立绘
在舞台上直接拖拽角色立绘可调整其在画面中的位置。位置信息会自动保存到当前剧本行中。

### 双击立绘
双击角色立绘打开属性面板，可编辑更详细的参数。

### 键盘操作
- 选中舞台元素后按 `Delete` / `Backspace` 键直接删除
- 删除操作会同步更新时间轴

## 场景切换

时间轴中每行的画面效果会在舞台预览中实时刷新：

- 点击时间轴中的不同行，预览自动切换到对应画面
- 背景切换支持过渡动画

## 注意事项

### 多角色隔离
舞台上的多个立绘角色使用全局唯一 ID 进行隔离管理，不会发生图层覆盖或互相干扰。

### 素材兼容性
舞台立绘和背景图片通过内置素材协议加载，不依赖浏览器环境。在 Electron 窗口内编辑以确保素材正常显示。

### 性能建议
如果同时展示大量高清立绘导致卡顿，可适当降低素材分辨率或减少同屏角色数量。
