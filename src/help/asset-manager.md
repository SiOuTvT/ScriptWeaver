# 素材管理

素材管理器是 ScriptWeaver 的统一资源管理中心，支持图片与音频的导入、预览、检索与管理。

---

## 界面布局

素材管理器分为三个区域：

- **左侧分类树**：按类型筛选素材（全部、背景、立绘、音频、视频、特效预设）
- **顶部工具栏**：即时搜索、排序切换、网格/列表视图、网格大小调节
- **卡片/列表区**：素材缩略图与元信息展示

## 导入素材

### 方式一：拖拽导入
直接将图片或音频文件从系统文件管理器拖入素材面板即可导入。

### 方式二：文件选择器
点击素材管理面板中的导入按钮，从文件选择器挑选文件。

### 支持格式

| 类型 | 格式 |
|------|------|
| 背景图片 | PNG、JPG、GIF、WebP |
| 角色立绘 | 推荐 PNG（透明通道） |
| 音频 | MP3、WAV、OGG |

## 素材管理

### 预览与播放
- 图片卡片悬浮可放大预览
- 透明 PNG 立绘在棋盘格底衬上清晰展示
- 音频卡片内置波形播放器，可试听

### 重命名
点击素材卡片上的名称可重命名。

### 删除
点击删除按钮移除素材。如果有剧本行引用该素材，删除前会弹出引用警告。

### 引用检索
点击素材的「引用」按钮，查看哪些剧本行使用了该素材，点击可跳转到对应行。

## 素材存储

素材文件存放在项目目录的 `assets/` 文件夹中，与 `.swproj` 工程文件同级。整个项目文件夹可自由移动或复制。

## 进阶操作

### 角色表情绑定
在角色管理器中，可以从素材库为角色添加表情图。角色的「默认表情」将被用作缩略图。

### 格式信息
每张素材卡片标注格式、分辨率和文件大小，方便判断是否适合使用场景。
