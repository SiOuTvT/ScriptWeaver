# 快速入门

本指南将带你完成 ScriptWeaver 的基本操作流程，从创建项目到导出作品。

---

## 第一步：创建项目

点击顶部工具栏的「新建」按钮创建一个空白项目。

此时你将看到一个空白的舞台预览区和时间轴。现在可以开始添加内容了。

## 第二步：导入素材

在开始创作前，建议先导入需要的图片和音频素材：

1. 点击左侧栏「素材管理」进入素材面板
2. 将图片或音频文件从文件管理器直接拖入素材面板
3. 素材会自动复制到项目的 `assets/` 目录下

支持的图像格式：PNG、JPG、GIF、WebP。透明 PNG 适合角色立绘。
支持的音频格式：MP3、WAV、OGG。

## 第三步：创建角色

1. 点击左侧栏「角色管理」进入角色面板
2. 点击「添加角色」按钮创建新角色
3. 为角色设置显示名、变量名和主题色
4. 在「表情包」区域为角色绑定表情图像
5. 可选：为角色配置默认缩放比例和出场站位

## 第四步：编写剧本

剧本在时间轴中编辑，每一行代表一个指令：

**添加场景行**：点击时间轴左侧的「添加行」按钮，选择「场景 / label」
**添加对话**：选择「对话」，在属性面板中选择角色和表情
**添加背景**：选择「背景」，从素材库中选择背景图片
**添加音频**：选择「音频」，选择 BGM / 音效 / 环境音

每行的顺序决定了游戏的播放顺序。你可以**拖拽行**来调整顺序。

## 第五步：实时预览

舞台预览区会实时显示当前选中行的画面效果：
- 拖拽立绘角色可调整其在画面中的位置
- 双击立绘可打开属性面板编辑详细参数
- 选中舞台元素后按 `Delete` 键可快速删除

## 第六步：保存项目

点击顶部工具栏的「保存」按钮，将项目保存为 `.swproj` 文件。素材文件会自动存放在工程目录的 `assets/` 文件夹中。

**便携性提示**：整个项目文件夹可以随意移动或复制，无需依赖系统路径。

## 第七步：导出作品

完成编辑后，点击顶部工具栏「导出 RPY」按钮：
- 选择「Ren'Py 工程」导出完整的 Ren'Py 项目文件
- 选择「Web 播放器」导出可在浏览器中预览的 Web 版本

---

完成以上步骤后，你就拥有了一个完整且可运行的视觉小说项目！
