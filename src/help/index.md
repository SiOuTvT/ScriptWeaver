# 欢迎使用 ScriptWeaver

ScriptWeaver 是一款面向 Ren'Py 的视觉化剧本编辑器，提供舞台预览、时间轴编辑、AI 辅助创作等完整工具链。

---

## 核心理念

**所见即所得**：编辑剧本的同时，舞台预览实时反馈画面效果。
**工程化管理**：素材、角色、剧本统一管理，一键导出 Ren'Py 工程。
**AI 赋能**：内置 AI 编剧 Copilot，帮你生成网状分歧剧情。

## 主要功能

| 模块 | 说明 |
|------|------|
| 舞台预览 | 实时渲染角色立绘、背景与对话，所见即所得 |
| 时间轴 | 多轨道剧本编辑，支持拖拽排序与节点图谱 |
| 素材管理 | 图片与音频统一管理，拖拽导入 |
| 角色管理 | 角色立绘、表情、主题色与配音绑定 |
| AI 编剧 | AI 生成剧本行、分歧树与角色对话 |
| TTS 配音 | 文本转语音，为角色生成配音 |
| 导出发布 | 一键导出 Ren'Py 工程或 Web 播放器 |
