# 时间轴与节点图谱

时间轴是 ScriptWeaver 的剧本编辑核心，提供多轨道视觉化编辑体验。

---

## 概述

时间轴位于舞台预览下方，默认高度 320px，可通过拖拽或一键折叠调整。每行代表一条剧本指令，行之间按顺序执行。

## 行类型

ScriptWeaver 支持以下剧本行类型：

### 场景标签（Label）
标记场景名称，用于定义代码块边界和跳转目标：
```
label prologue
label chapter_01
```

### 对话行（Dialogue）
角色对话，包含说话者、对白文本和可选的表情：
- **角色**：选择已创建的角色
- **表情**：选择该角色的表情（如 `happy`、`sad`、`default`）
- **文本**：输入对话内容
- **配音**：可选绑定 TTS 生成的语音文件

### 背景行（Background）
设置当前场景的背景图片：
- 从素材库中选择背景图像
- 支持过渡效果

### 音频行（Audio）
播放背景音乐、环境音或音效：
- **BGM**：背景音乐（可循环）
- **环境音**：场景环境音（如雨声、街道嘈杂声）
- **音效**：事件触发音效

### 选择支行（Choice）
展示选项给玩家，每个选项可跳转到不同标签：
```
choice:
  - "选择A (跳转到 label branch_a)"
  - "选择B (跳转到 label branch_b)"
```

### 变量操作行（Variable）
修改游戏变量，如好感度、选择标记等：
```
操作：heroine_trust += 1
操作：flag_met_king = True
```

## 操作方式

### 添加行
1. 点击时间轴中的空行位置，或使用「添加行」按钮
2. 在弹出的菜单中选择行类型
3. 新行会插入在当前选中行的下方

### 编辑行
- 点击行可选中并在属性面板中编辑
- 选中行后舞台预览会自动切换到该行画面

### 删除行
- 选中行后按 `Delete` 或 `Backspace` 键
- 或在属性面板中点击「删除」按钮

### 调整顺序
- 拖拽行标题栏可在时间轴中重新排序

### 时间轴折叠
- 点击底部面板的折叠按钮可将时间轴收起为 38px 的标签栏
- 这会把更多空间让给舞台预览区

## 节点图谱

节点图谱是时间轴的**图形化视图**，展示剧情分支结构：

### 切换视图
点击底部面板的「节点图谱」标签从时间轴切换到图谱视图。

### 图谱结构
- **节点**：每个场景标签为一个节点
- **连线**：节点间的流程走向
- **颜色编码**：不同类型节点有不同颜色标记
- 选择支行会显示分支路径

### 导航定位
- 点击图谱中的节点可定位到时间轴对应的行
- 选择支路径一目了然，方便追踪剧情分支

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Delete` / `Backspace` | 删除选中行 |
| `↑` / `↓` | 上下移动选择行 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
