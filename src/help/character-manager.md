# 角色管理

角色管理是角色的完整资料库，管理角色的外观、表情、配音和出场设置。

---

## 面板布局

### 左侧：角色名册

以主从列方式展示所有已创建的角色：
- **头像**：角色的默认表情大图（无图时显示首字母 + 主题色圆底）
- **主题色花纹顶条**：角色专属颜色装饰条
- **微型对话框文本样式预览**：展示角色名在对话框中的样式效果

悬浮操作按钮：
- **复制**：复制角色配置
- **上移 / 下移**：调整角色出场顺序
- **删除**：删除角色（有剧本引用时弹出确认提示）

### 右侧：详情编辑区

点击左侧角色进入详情编辑：

#### 基本信息
- **头像区**：默认表情大图预览
- **显示名**：角色在游戏中显示的名称
- **变量名**：角色在代码中的变量标识（如 `heroine`）
- **主题色**：拾色器 + 十六进制色值输入，决定对话框角色名颜色

#### 声色与定位预设
- **CV 语音包**：绑定 voice 类音频作为角色配音基础
  - 可点击播放按钮试听
  - 播放中显示停止按钮
- **默认出场缩放比例**：50% - 150% 范围滑块
- **默认出场槽位**：五档预设站位（左近 / 左远 / 居中 / 右远 / 右近）

#### 对话框样式预览
- 实时展示角色名在对话框中的渲染效果
- 角色名按主题色显示
- 支持**常规**和**加粗**两种字重即时切换

#### 表情包大观墙
- Grid 网格大图卡（3:4 比例）
- 透明 PNG 显示棋盘格背景底衬
- 悬浮放大查看
- 操作按钮：
  - **Star**：设为默认表情
  - **重命名**：修改表情 Key（如 `happy`、`sad`、`angry`）
  - **删除**：删除表情绑定
- 添加表情方式：
  - 「从素材库添加」：选择已导入的图片
  - 拖入 OS 图片文件：自动落盘并绑定为表情
  - 点击加号区域：打开文件选择器

## 角色配置字段

每个角色包含以下可配置字段（存储在 `.swproj` 中）：

| 字段 | 说明 | 必填 |
|------|------|------|
| `id` | 角色唯一标识 | 是 |
| `displayName` | 显示名 | 是 |
| `variableName` | 变量名 | 是 |
| `themeColor` | 主题色 | 是 |
| `expressions` | 表情 Key 到素材 ID 的映射 | 否 |
| `voiceAssetId` | 配音音频素材 ID | 否 |
| `defaultScale` | 默认缩放比例 | 否 |
| `defaultSlot` | 默认出场槽位 | 否 |

## 注意事项

- 删除角色前请确认剧本中没有该角色的对话行
- 默认缩放和槽位目前存储后可在舞台预览中使用
- 表情图片需先导入素材管理，再绑定到角色
