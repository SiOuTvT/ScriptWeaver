# 快捷键速查

本文档列出 ScriptWeaver 中所有可用的键盘快捷键。

---

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z` | 撤销最近操作 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做 |
| `Ctrl + N` | 新建项目 |
| `Ctrl + O` | 打开项目 |
| `Ctrl + S` | 保存项目 |
| `Ctrl + E` | 导出 RPY |

## 舞台预览快捷键

| 快捷键 | 功能 |
|--------|------|
| `Delete` / `Backspace` | 删除选中的舞台元素（立绘角色） |
| 单击立绘 | 选中角色 |
| 拖拽立绘 | 移动角色位置 |
| 双击立绘 | 打开角色属性面板 |

## 时间轴快捷键

| 快捷键 | 功能 |
|--------|------|
| `Delete` / `Backspace` | 删除当前选中的行 |
| `↑` | 选中上一行 |
| `↓` | 选中下一行 |
| 双击行 | 跳转到对应舞台预览 |

## 视图切换快捷键

| 快捷键 | 功能 |
|--------|------|
| 点击左侧栏图标 | 切换功能面板 |
| 点击底部标签 | 切换时间轴 / 节点图谱视图 |
| 点击折叠按钮 | 展开/收起时间轴 |

## 主题切换

| 操作 | 功能 |
|------|------|
| 点击顶部 Sun/Moon 图标 | 切换深色 / 浅色模式 |

## 提示

- 在文本输入框中编辑时，`Ctrl + Z` / `Ctrl + Y` 会优先执行文本框内的撤销/重做，不会触发全局撤销
- 大部分拖拽操作（时间轴排序、立绘移动）会立即保存，可按 `Ctrl + Z` 撤销
