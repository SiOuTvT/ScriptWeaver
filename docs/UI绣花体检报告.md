# ScriptWeaver UI 绣花体检报告

检查范围：全站 48 个界面组件 + 全局设计系统（src/index.css）。
检查维度：可读性、一致性、间距节奏、图标体系、无障碍、文字底线。
依据：你的硬性规范（Noto 同族、字号 12/13/14/15/16/18、下限 12px、字重≤600、禁 emoji 图标、浅色分层清晰）。

---

## 一、已修复（本次落地）

### 1. 全站小字低于 12px 底线（最大宗问题）
- **现象**：全站散布约 180 处 `text-[10px]` / `text-[11px]`，覆盖 25 个文件。徽标、时间戳、说明文字、面板眉标全部偏小，正是「看着不舒服、挤、累眼」的主要来源。
- **修复**：所有 `text-[10px]`、`text-[11px]` 统一升为 `text-[12px]`；全局 `.eyebrow` 眉标（面板小标题）由 11px 升 12px。
- **涉及**：素材库、角色、发布与导出、舞台、导入弹窗、剧本总览、AI、特效、版本历史、协作日志、时间轴、设置、诊断、命令面板、模板、树图、多文件导出、左侧栏、变量监视、选择支、特效挂载、协作徽标、App 根组件等。
- **结果**：全站 0 处残留 10/11px 文字，字号体系回到 12px 起。

### 2. 左侧栏「大而不整」
- 宽度 208px → 176px → 144px；去掉每行末尾数字编号；分组标题去掉「— —」破折号；去掉底部大开关按钮；行距收紧。已在上一轮完成。

### 3. 发布与导出页「一堵墙」
- 新手模式下只显示「试玩 / 打包 / 发网页」三个大按钮，其余收进「更多选项」折叠。已在上一轮完成。

## 三、建议后续（低优先，看需要再做）

2. **EffectsLab 注释里的 emoji**（🎭📐💻）可顺手清理，纯洁癖项。
3. **稀疏度复核**：等你看完这轮效果，若还有具体页面觉得「挤」，告诉我页面名，我按「大按钮 + 折叠」模式继续收。
4. **暗色模式抽样复核**：深色主题字号受益于本次放大，若个别深色对比偏弱可再微调。
