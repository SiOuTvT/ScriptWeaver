状态：方案阶段，未改动任何代码。

## 一、现状盘点（冗余点）

当前 `LeftSidebar` 导航为 17 项平铺，只用注释分组，存在三处明显冗余：

1. 导出三页各自为政
   - 导出设置：Ren'Py 工程 + 游戏信息（标题/封面/图标/结局）
   - 多格式导出：md / txt / html / csv 文档导出
   - Ren'Py 生态：社区插件 / 语法学院 / 能力审计
2. 设置双页重叠
   - 设置中心（含「外观」tab）
   - 外观主题（主色预览，本质是设置里「外观」的放大版）
3. 脚本三视图看同一份数据，分工未讲清
   - 场景导航（主工作区）
   - 剧本总览（统计洞察）
   - 脚本编辑（DSL 原文）
4. 顶栏「历史」「协作」与侧栏「协作日志」「工程体检」散落，未归一组。


- 选中分组标题可折叠该组，进一步收窄长列表。

## 四、缺口功能（按优先级，补全才叫完整 VN 工坊）

1. 存档 / 读档点可视化（Ren'Py `save_label` 标记，时间轴上打点）
2. 测试运行显眼入口（引擎预演已有 `renpyStageProject`，提到顶栏常驻按钮）
3. CG 画廊 / 回想系统配置
4. BGM / 音轨混音时间轴（细粒度音频，目前只能整段放置）

6. 项目模板、导入已有 Ren'Py 工程
7. 设置项（音量 / 文字速度）可视化写进 `options.rpy`
